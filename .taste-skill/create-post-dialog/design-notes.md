# 创建带班岗位弹窗优化

## 方向和对象

组件优化，沿用系统品牌与现有ForUI，按skill的单组件规则不重新抽取方向或色板。主问题：为哪些班级的哪些可带班时段创建岗位？主要内容为范围树与真实作息网格。

对象包括学段、年级、班级、星期、时段、节次时间、免任课标记、已有岗位、连续节次、实际合班、人员设置和派生创建数量。课格可用性继续由原有规则计算，未改分配/持久化逻辑。

## Before

用户截图：人员设置独占一行；左侧树被固定高度截断，未延伸到右侧设置区底部；节次轴被误画为禁用格，时段、禁用、可选不够清楚；底部统计按Wrap顶端对齐。

## After 与截图检查

- 桌面：活动类型/人员设置/继承摘要同行；班级范围填满同一工作区高度，范围树与右侧表单分别滚动。
- 窄窗口：活动类型标签与下拉框保持为一组，班级树和作息上下排列，排班方式可滚动到达；底部操作固定可见。
- 颜色使用系统token派生：浅蓝时段条、浅底节次轴、灰色禁用格、白色可选格、蓝色选中格及勾选。状态同时有文字或图标，不仅依赖颜色。图例与实际格子使用同一颜色函数。
- 页脚：统计位于左侧，按钮位于右侧，桌面垂直居中；窄窗口分行。
- 检查1440/768/390与深色截图。桌面左右底边一致、字段不散开；无多余标题、无独立教师负载卡；零创建数如实显示0，按钮禁用。
- 截图使用内存样本12班级、已有90岗位，其中选择6班级、1课格将创建6岗位；没有写入用户数据库。
