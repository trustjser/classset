# 作息设置精简实施计划

## 目标

按最新设计反馈调整作息设置：移除按星期覆盖每日节数的交互，增加全校范围免任课汇总，时段固定为早上、上午、下午、晚上，不允许新增自定义时段；移除左侧公共时段管理卡片，同时保留表格内公共时段行和右侧时段编辑能力。

## 设计与架构约束

- 继续沿用 Flutter + Riverpod + `SchoolRepository` 分层；Widget 不直接访问 Drift。
- 免任课仍遵循现有学校/学段/年级/班级范围继承与覆盖规则；汇总卡片展示各学段数据中的现有免任课记录。
- 旧版 `RoutineOverride` 数据模型与 Drift schema 暂时保留，避免本次 UI 调整引起数据库迁移；作息页不再读取或写入每日节数覆盖。
- 固定四个时段按早上、上午、下午、晚上排序。保存时继续保留公共时段和免任课记录；旧自定义时段的映射/保留按 ID 和时段语义尽可能兼容。
- 保持已完成的撤销/重做、公共时段插入节次之间、班级继承上级免任课等既有行为。
- 不新增或运行测试；只做格式与 diff 检查。若本机没有 Flutter 热重载 MCP，则如实报告。
