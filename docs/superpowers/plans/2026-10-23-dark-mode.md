# 暗色模式与顶部切换 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a user-controlled dark theme to the whole desktop app, with a switch in the app header.

**Architecture:** Keep theme mode in the application UI layer and pass it from the app root to the header control. Extend the existing AppTheme palette for dark surfaces and text, then make the current shared widgets and feature screens resolve the active palette consistently; configure both Material and Forui themes from the same mode.

**Tech Stack:** Flutter, Riverpod, Material 3, Forui.

**Spec:** User request in this task; project visual tokens and desktop constraints in `design/DESIGN.md`.

## Global Constraints

- Keep persistence and domain behavior unchanged.
- Use the existing Riverpod and theme patterns; do not add a new theme dependency.
- Keep the default mode light; the user can switch modes from the top header.
- Do not add or run tests unless the user requests testing or verification.
