# 带班草稿撤销与重做

每次已应用的草稿修改记录完整快照，最多保留 100 步。岗位创建、批量移除、教师指派、候选池、全局/岗位匹配和智能匹配各为一步；筛选、框选、弹窗内未应用输入及保存不产生操作。

保存保留本页历史，恢复快照沿用当前数据库 revision；脏状态与最近保存内容比较。成功发布或接收外部新草稿清空历史。历史版本只读，保存/发布/匹配执行中禁用历史。历史不持久化，离开页面结束。

使用 ForUI 按钮，提示操作名称；支持 Cmd/Ctrl+Z、Cmd/Ctrl+Shift+Z、Ctrl+Y。输入框与弹窗不触发页面历史。

- [x] 失败测试：批量操作原子恢复、保存后的 revision 和脏状态、撤销后新编辑清空重做。
- [x] 接入唯一修改入口，忽略无内容变化的应用，提供按钮和快捷键。
- [x] 验证配置、智能匹配、文本/弹窗隔离、发布与外部刷新边界。
- [x] 格式、静态分析、带班回归、macOS 构建、截图检查。


## 验证结果

- 9 项专项测试通过：100 步边界、独立深快照、语义无变化不记历史、批量移除原子恢复、保存后 revision/脏状态、候选池与岗位规则、快捷键/输入框/弹窗隔离、创建/指派/清除/真实智能匹配、真实发布与外部刷新边界。
- 43 项带班定向测试通过；另有 1 项临时截图测试通过（已删除临时测试文件）。未执行全量测试。
- 局部静态分析无问题，格式检查与 `git diff --check` 通过，macOS debug 构建通过。
- 1440 / 768 / 390 宽度截图无溢出；撤销/重做入口在带班周期选择器右侧。
- 代码审查发现的“dirty 时延后外部来稿，撤销回 clean 后仍停在旧 revision”已增加真实 SQLite 失败复现并修正；保存自身回声不会清历史，外部较新版本会在可接收时清历史并成为当前草稿。
