# 临时调代课功能设计

## 1. 目标与范围

面向教务员，在实际日期的课表上完成临时换课、移课和代课，保留常规周课表。每次操作经过预览确认，形成可查询、可取消、可导出的调整记录。

首版采用“日期周表＋调整记录”，替代现有 PRD 的父子任务树。支持单次调整及日期范围内重复调整，不包含自动连锁调课、审批和在线通知。

## 2. 页面结构

左侧导航新增 **“调代课”**，页面包含两个页签，保留相同的日期、学段、班级和教师筛选条件。

**实际课表**

- 顶部提供周切换、“本周”、班级／教师视图切换，以及“查看调整记录”。
- 主区展示带具体日期的周课表，日期旁标明教学周、单双周及补课映射；按实际作息显示周末课程。
- 调整后的课格显示当前课程及“换课／移课／代课”小标签，点击可查看原安排和关联记录。
- 点击课格，在右侧面板开始调整；窄窗口改为全宽面板。保留点击选择目标的完整操作方式，拖拽作为快捷入口。

**调整记录**

- 每行显示调整类型、涉及日期、班级、课程与教师、调整前后、原因和状态。
- 支持按类型、班级、教师、日期和状态筛选，以及查看详情、取消和导出。
- 已取消记录继续保留，默认显示有效记录，可切换查看全部。

视觉沿用 `design/DESIGN.md`：温暖浅底、轻分隔、蓝色主操作；状态同时使用文字和颜色。

## 3. 操作流程

统一流程：**选择课程 → 选择调整方式 → 设置目标和范围 → 预览 → 确认生效**。

| 类型 | 操作与限制 | 确认内容 |
|---|---|---|
| 换课 | 选择同一班级另一实际课次，两节课交换时间；允许跨日期、跨周 | 两节课各自的“原日期节次 → 新日期节次”，保留各自科目与教师 |
| 移课 | 选择该班级的实际空课位，原位置变为空位 | 课程、教师及时间变化 |
| 代课 | 保留时间和班级，选择代课教师；默认保留科目，可另选科目 | 原教师／科目 → 代课教师／科目 |

目标周表标明“可选”“不可选”，不可选项可查看具体原因。代课候选支持同科、同年级、同班筛选，显示空闲状态及本次新增课次数；可以查看候选教师同期课表。

**生效范围**

- 默认“仅本次”，直接显示选中日期。
- 选择“日期范围”后，按选定星期和节次逐周展开；换课、移课保留源与目标的日期间隔，两端均须落在范围内。
- 按教学日历、单双周及补课映射生成实际课次，预览列出每次日期、变化与校验结果。
- 无实际源课次的日期不产生调整，并说明原因；目标不存在或冲突的课次必须修正或明确移除。
- 单次操作中的全部课次一次提交；失败时全部保留原状。

预览底部统一提供“返回修改”和 **“确认调整（N次）”**。原因选填。成功后同步更新班级、教师课表并定位受影响课格。

## 4. 校验、取消与异常

- 校验使用叠加已有有效调整后的实际课表；同时检查换课双方，不能只检查目标格。
- 阻止教师时间重叠、班级冲突、场室超容量、无效课位及现有硬性排课约束；跨学段按起止时间判断。合班、连排作为完整课组处理。
- 锁定沿用现有班级和教师规则，面板列出阻止调整的锁及解锁入口。
- 未配置教学日历时，提示先完成配置；常规课表存在待协调变更时，暂停新增调整。
- 确认前重新校验；课表或其他调整发生变化时，要求刷新预览。
- 常规课表变化使来源失效时，将相关调整标记“需处理”，列出失效项，禁止静默匹配其他课程；受影响课次暂停导出和计入实际工作量。
- 取消前展示恢复结果并重新校验。一次换课整体取消；日期范围记录首版整体取消。
- 如存在依赖此结果的后续调整，列出记录并引导先取消后续调整；取消本身也必须完整成功。

导出提供“教师通知”“班级通知”和“调整明细”Excel，使用实际日期、节次、时间及调整前后信息。已取消记录默认不进入通知；“需处理”项必须先解决。

## 5. 验收与默认约定

- 换课、移课、代课确认前不改变课表；确认后各视图一致，重启后仍保留，常规周课表不变。
- 覆盖跨周、单双周、节假日、周末补课及不同学段作息。
- 教师冲突、场室容量、锁定和课组限制均显示明确原因；批量范围中任一失败不能部分保存。
- 覆盖连续调整、依赖取消、原课表变化、重复点击确认和保存失败。
- 导出的教师与班级通知必须与当前有效调整一致，实际课次不可按周平均推算。
- 桌面与窄窗口均可完成选择、预览、确认和取消；键盘可操作，不能只靠颜色识别状态。

默认由教务员在本地直接确认生效；工作量统计后续读取同一套有效调整记录，本次不新增完整统计页面。
