设计说明 · 优化对照与状态清单（点击展开）

本轮改动（对照两张原截图）

  • 学科色降噪：整格高饱和填充 → 3px 左侧色条 + 极浅底，科目文字统一深色。保留辨识度，消除「彩色积木墙」。
  • 删除常驻「检测中」：系统检测态不是课程信息，改为仅在冲突/异常时出现角标，每格少一行噪音。
  • 流程可见：新增三步流程条（选择课次 → 选择目标 → 确认生效）替代底部居中那句弱提示，当前步骤与下一步动作同时可见。
  • 选择态统一：源课次=蓝实线+「源」标，可选目标=蓝虚线+hover「⇅ 选为目标」，已选目标=绿实线+「目标」标，不可选=降透明度。不再只在零星格子挂「换课」小按钮。
  • 控件符合项目约定：班级/教师视图、调整方式一律 TDesign 单选框（16px 圆环 + 8px 内点），不用分段控件；主色沿用 DESIGN.md 的 #0075DE。
  • 抽屉升级：「调整课次」→ 带 2/3 步骤徽标的「发起调整」；目标课次用虚线空态卡明确承接动作；底部禁用按钮配一句说明，不再让用户猜为什么点不动。
  • 顶栏收敛：不在顶导航展示「保存 / 已自动暂存」，保存状态移到侧栏底部的「本地数据」区。
  • 数据修正：原抽屉写「11 月 6 日（周四）」，但列头 11/06 是周五、11/05 才是周四；本稿以「11 月 5 日（周四）」为准。
  • 列头与节次：周三加「今天」胶囊，解释蓝色高亮；节次列压成「上午/下午 · 第 N 节 · 时间」三行紧凑信息。

已覆盖状态

  • 交互四态：hover / focus-visible / active / disabled（含禁用主按钮与不可选课格）
  • 业务状态：初始态、已选源课次、已选目标、预览确认、代课候选（含占用禁用）、已生效调整角标、空课位、调整记录空态
  • 键盘：Tab 顺序自然、Enter/Space 选中课格、Esc 关闭弹窗或取消调整、焦点环不被移除
  • 降级：1180px 侧栏收窄 + 面板转底部抽屉；768px 侧栏隐藏、课表横向滚动

契约 token 入口

  • 全部集中在 :root：--blue / --blue-soft / --canvas / --surface / --ink / --ink-2 / --muted / --border / --radius-card / --radius-control / --sp-*；学科色在 [data-subj="…"] 中集中定义，改色只动一处。

边界

  • 静态 HTML 原型，状态仅保存在当前页面会话；未接入 Flutter / Forui，未做持久化。
