# 课集 ClassSet · 晴空蓝日程

> 全项目设计规范。新页面、公共组件与后续改造均以本文为准；业务规则仍以 PRD 和领域模型为准。
> 运行时 token：`lib/core/theme/app_theme.dart`；科目色：`lib/core/theme/subject_colors.dart`。
> [查看明暗视觉样张](design-language.html)。样张用于审阅设计语言，包含示例数据，不代替实际 Flutter 页面。

## 1. 产品气质

课集是一张可以整理、推敲、放心使用的学校日程。采用用户选定的“晴空蓝”：清透的冷白画布、纯白内容面板、清晰的蓝色交互与深蓝灰夜间表面。舒展、轻盈、有秩序，让课表和具体的人占据注意力。

- 内容先于容器。先看到“这一周怎么安排”，再看到用于调整的工具。
- 用字级、留白与底色形成层次；静态面板不靠投影浮起。
- 晴空蓝只用于主操作、当前位置、焦点和选中态。普通图标、统计数字、标题使用墨色。
- 复杂能力按任务展开；默认页面不过度展示规则、报表和配置入口。
- 桌面排课保持效率；亲和感来自文字、节奏和颜色，不以降低课表可读性为代价。

避免：大面积饱和蓝导航框架、满屏数据大卡、每块内容一层边框、彩色图标方块、渐变品牌条、玻璃质感、装饰性动效、无业务意义的欢迎语和指标。

## 2. 明暗主题一起设计

方案名“晴空蓝”，浅色使用晴空与冷白，深色使用夜空蓝灰。默认跟随系统，顶部保留主题切换入口。用户手动切换在当前运行会话生效；本轮未增加跨启动的主题偏好持久化。

以下数值均为不透明 sRGB；Flutter 使用对应 ARGB 值。禁止通过反色、全局透明度或滤镜得到深色主题。

| 语义 token | 晴空蓝 · 浅色 | 夜空蓝 · 深色 | 用途 |
| --- | --- | --- | --- |
| `canvas` | `#F4F7FC` | `#111722` | 页面与工具栏画布 |
| `surface` | `#FFFFFF` | `#1B2433` | 内容面板、侧栏、菜单与对话框 |
| `tableHeader` | `#F3F5F9` | `#242E3F` | 表头、弱分组、输入底色 |
| `ink` | `#202A3D` | `#EDF2FC` | 标题、正文、数据 |
| `inkSecondary` | `#5E6B80` | `#A6B4CC` | 描述、次级操作 |
| `muted` / `helpIcon` | `#606F86` | `#9EAEC8` | 辅助文字、占位与帮助图标；不等同禁用态 |
| `accent` | `#2864DC` | `#97BAFF` | 主操作、链接、焦点 |
| `onAccent` | `#FFFFFF` | `#162B50` | 品牌实底上的文字和图标 |
| `selection` / `sidebarActive` | `#EAF1FF` | `#253957` | 选中底；与普通悬停区分 |
| `border` | `#DCE3EF` | `#34425A` | 结构分隔；不独自承担控件识别 |
| `controlBorder` | `#7E8BA3` | `#7186A6` | 需要清晰轮廓的控件边界 |
| `tableDivider` | `#E6EBF4` | `#303C52` | 表格细分隔 |
| `purple` | `#6E5AAC` | `#C3B3F5` | 少量学段分类色，不用于大面积装饰 |
| `success` / `successSurface` | `#1F765E` / `#E5F4ED` | `#78D8B4` / `#193D35` | 已保存、已完成 |
| `warning` / `warningSurface` | `#875D18` / `#FFF4DD` | `#F0CC83` / `#423824` | 需要检查、待确认 |
| `destructive` / `destructiveSurface` | `#B74752` / `#FCECEF` | `#FFA4AE` / `#472A36` | 冲突、错误、删除 |
| `dialogBarrier` | `#111B2D` 40% | `#08101E` 70% | 浮层遮罩 |

正文、辅助文字与主要状态前景在指定底色上至少 4.5:1；焦点和承载信息的图标至少 3:1。禁用控件同时提供禁用语义并降低强调，不能把正常辅助文字做成禁用灰。状态始终带文字，冲突不能只画红色。

深色主题使用更浅、饱和度更低的强调色，主按钮使用深蓝墨字。禁止统一写死白字；必须取 `onAccent` / `ColorScheme.onPrimary`。阴影不作为暗色层级来源，浮层依靠表面色、边界与遮罩分离。

## 3. 排版

优先使用平台系统字体：macOS 的系统无衬线和苹方、Windows 的 Segoe UI 和微软雅黑，其他平台使用系统回退。不引入在线字体依赖；中文正文不混用装饰衬线体。使用 `Theme.of(context).textTheme` 和 Forui typography。

| 角色 | 字号 / 行高 | 字重 | 使用 |
| --- | --- | --- | --- |
| 页面标题 `headlineSmall` | 28 / 1.25 | 600 | 页面内容顶部，只出现一次 |
| 模块标题 `titleMedium` | 16 / 1.4 | 600 | 内容分组 |
| 紧凑标题 `titleSmall` | 14 / 1.35 | 600 | 面板与列表标题 |
| 舒适正文 `bodyLarge` | 16 / 1.5 | 400 | 引导与触控布局正文 |
| 正文 `bodyMedium` | 14 / 1.5 | 400 | 说明、字段与列表 |
| 辅助 `bodySmall` / `labelSmall` | 12 / 1.5 | 400–500 | 日期、单位、次级标记 |

- 标题左对齐。不要全大写追踪字距制造“控制台”气质。
- 人名、班级名和科目名保持主墨色；不因条目已读或未选中就降为灰色。
- 时间、节数和列内数字使用等宽数字；相同单位对齐，单位紧随数值。
- 长名称优先换行；必要时省略并提供 Tooltip 或详情。不得静默裁掉关键标签。
- 系统文字放大后允许标题、操作和标签重排，不锁死文字容器高度。

## 4. 空间与形状

| Token | 值 | 使用 |
| --- | --- | --- |
| 间距序列 | 4 / 8 / 12 / 16 / 24 / 32 / 40 / 48 | 同级保持一致 |
| `pagePadding` | 32 | 宽窗口页面内边距 |
| `compactPagePadding` | 16 | 小于 880 的内容区域 |
| `pageSectionGap` | 24 | 页面主要模块之间 |
| `cardRadius` | 20 | 一级内容面板 |
| `controlRadius` | 12 | 标准输入、按钮 |
| 标签圆角 | 4–8 | 日期状态、科目标记；不把所有东西做成胶囊 |
| 静态面板投影 | 无 | 以表面色和留白区分 |
| 浮层 | 允许轻投影 + 遮罩 | 菜单、对话框，服从主题 |

外层面板承载一个完整任务，内部先用标题、间距或列表分组。避免“卡片套卡片”，禁止给普通面板同时叠加强描边与投影。表格单元格可以保留必要分隔，不把整张课表拆成漂浮卡片。

## 5. 应用框架与响应式

- 桌面侧栏沿用 244，收起后 70；顶部栏 62。侧栏与画布轻微分色，顶部栏融入画布，减少横竖框线。
- 学校、当前学期和本地保存状态位于固定上下文位置。不要重复以大卡片占据每个页面的首屏。
- 导航按排课准备、排课与课表、更多分组；图标使用现有 Material 线性族，选中项以浅蓝底、文字字重和选中语义共同表达。
- 每页主要内容只设一个标题与一个主操作；工具栏中的筛选、导入、导出从属于任务。
- 内容区域小于 880 时采用 16 边距；双栏工作区不足 1040 时折叠或纵向排列。断点根据实际可用内容宽度判断。
- 标题与操作默认使用 `AppPageHeader` 的响应式布局；操作自动换行，不挤压标题。
- 普通设置页正文保持易读宽度（建议最大 1120）；课表、教师矩阵和日历可使用全部工作区宽度。
- 375 宽的窄视图应把任务分为单列和详情；主应用的完整手机导航不在本轮范围。仅课表等二维数据区允许有明确提示的内部横向滚动，页面本身不得横向溢出。
- 指针控件通常 36–40 高，紧凑编辑区需保证清晰焦点；触控环境目标至少 48×48，间距至少 8。禁止全局放大所有表格行来代替响应式设计。

## 6. 组件语言

### 按钮与操作

主按钮使用 `accent + onAccent`，动词具体：“开始排课”“保存修改”“确认应用”。次按钮用中性浅底或轻轮廓，低频操作放入更多菜单。危险操作使用 `destructive` 并与保存分开。禁用、悬停、按下和焦点均需可辨识；不要去掉点击反馈。

批量动作在选中对象后出现。耗时任务显示进行中的状态并防止重复提交；不要每次局部保存都弹模态框。

### 表单

标签在字段上方或沿现有紧凑表单的左列对齐。输入框用表面色、清晰边界和 2 px 品牌焦点环。常用选项先出现，规则说明紧邻受影响的字段。错误说明“哪里有问题、怎么修正”，不只显示“无效”。

复杂设置保留“修改 → 预览差异 → 确认应用”的流程。旧课表仍可查看，待协调时清楚表达只读；成功写回后再移除保护。

### 列表、标签与空状态

普通列表用行距和低对比细线分隔。标签仅表达分类或状态，不给每条信息都套彩底。计数紧邻对象，例如“教师 · 32 人”，不额外制造指标墙。

空状态包含一个具体标题、一句下一步和一个可选操作；使用小型中性线性图标，不用大型插画占据工作区。示例：“还没有学期 / 创建学期后，就可以安排作息与课程 / 新增学期”。错误状态提供重试或返回编辑。

### 对话框与抽屉

标题说明正在编辑的对象，描述简短，表单内容超高时滚动。操作区靠底、顺序稳定，始终可以取消或返回；未保存时离开应遵循现有草稿保护。表单不得被遮罩、固定底栏或键盘盖住。Esc 关闭可取消的浮层，关闭后焦点回到触发控件。

## 7. 课表与科目颜色

课表是主内容。星期、日期、节次和时间在视觉上稳定，课程与教师姓名优先。今日用轻强调，当前选择用 `selection`，冲突用“冲突”文字及标记；不要让三种状态共用一个饱和色块。

十种科目色沿用 ID 稳定散列，颜色不落库，也不因排序变化而变化。浅色前景更深，深色前景更浅；格底以同色 8% / 12% 叠在 `surface`。颜色辅助辨识，科目名称必须保留。

## 8. 动效与无障碍

- 反馈 120 ms，页面进入与主题切换 180 ms，退出 120 ms。使用 `AppTheme` 动效 token。
- 导航以淡入或极小位移表达切换；禁止面板逐个飞入、循环闪烁和装饰性弹跳。
- `MediaQuery.disableAnimations` 为真时，应用框架切换不做动画；数据正确性不依赖动画结束事件。
- 键盘 Tab 顺序匹配阅读顺序；焦点清晰可见，悬浮操作也必须能用键盘抵达。
- 图标按钮有可访问名称；导航暴露选中状态；装饰图标不重复朗读相邻文字。
- 拖拽排课保留现有点击/菜单替代路径。减少动态效果和放大文字时，保存与确认仍可操作。

## 9. 日历领域约束

视觉更新不得改变以下语义：

- 学期保存第 1 教学周锚点与教学周数，不虚构独立起止日期。第 1 周为单周，之后交替；停课、补课不移动周次锚点。
- 上课日和每日节数归属分学段作息，日历页仅链接到作息设置。
- 月历周一至周日排列，每行左侧只显示一次教学周与单双周标记。
- 例外包含日期、范围、类型和说明；补课映射至采用的教学周，并允许各学段采用不同作息日。

## 10. Flutter 落地与迁移

```dart
final colors = context.appColors;
// 新组件用语义命名；不可用 Colors.white 假设主按钮前景。
ColoredBox(color: colors.selection, child: Text('已选中',
  style: TextStyle(color: colors.accent)));
```

- `AppThemeColors` 是应用颜色来源；Material、Forui 和业务组件都从它映射。`blue`、`selectedBlue` 是兼容已有调用的字段，语义已分别对应 `accent`、`selection`；新增代码用后者。
- `AppSurface` / `AppSectionPanel` 复用 20 圆角和无静态投影；`cardShadow` 保留兼容入口，当前明暗均为空。
- 不手工重着色品牌 Logo；现有蓝橙标志保留原始资产。它是品牌资产例外，不能成为页面恢复大面积蓝色的理由。
- 本轮覆盖全局主题、应用框架、公共标题与表面、科目色，及带班页头、日历例外、班级预览和排课复选框的主题映射。现有页面的所有局部字号、控件密度与自定义动效仍需按本规范逐页迁移，不宣称全界面已重排。
- `design/` 中其他旧 HTML 原型是历史布局参考。其蓝色、固定白底、旧字号不得覆盖本文；无需批量修改历史原型。
- 不引入新的 UI 框架、字体服务或数据库 schema；页面继续通过 Provider 和 Repository 操作数据。
