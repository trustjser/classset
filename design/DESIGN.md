# 课集 ClassSet 界面设计规范

本文根据用户提供的温暖极简风格参考，沉淀课集桌面端界面的可复用规范，并补充本产品的导航、表单、日历与响应式约定。它是设计参考，不替代 PRD 中的业务规则。

## 设计目标

- 让排课准备工作清楚、安静、可信；帮助教务人员顺着“资料 → 作息 → 排课 → 课表”完成任务。
- 使用温暖克制的工作空间气质，避免传统 B 端系统常见的密集表格、重边框、满屏按钮和强烈状态色。
- 重要操作容易找到，常用内容直接编辑；复杂规则通过简短说明和有上下文的对话框解释。
- 以桌面端为主，平板端可收起导航、上下排列内容、保留清晰的触控目标。

## 视觉语言

方向关键词：温暖、留白、轻层级、柔和的蓝色强调、少量状态色。整体参考 Notion Warm Workspace，但保持课集自己的信息组织和排课语义。

| Token | 值 | 用途 |
| --- | --- | --- |
| `canvas` | `#F6F5F4` | 主内容画布、页面外围 |
| `surface` | `#FFFFFF` | 侧栏、卡片、输入框、菜单 |
| `accent` | `#0075DE` | 主操作、当前导航、链接、焦点 |
| `accent-soft` | `#E8F1FC` | 选中态、浅蓝提示区 |
| `text-primary` | `#1A1A1A` | 标题与主要内容，避免纯黑 |
| `text-secondary` | `#615D59` | 正文说明、次级操作 |
| `text-muted` | `#A39E98` | 占位、辅助信息、禁用态 |
| `border` | `rgba(0,0,0,0.08)` | 轻分隔、输入框描边 |
| `success` | `#2BA471` | 保存状态、补课等正向状态 |
| `warning` | `#C98A2B` | 需要留意但不阻断的提示 |
| `danger` | `#D54941` | 停课、删除、错误状态 |

状态色使用淡色底和清晰文字搭配。蓝色是主要交互色；不要给每个导航项、卡片或数据都加色块。

## 字体与层级

- 字体优先级：Inter、系统中文字体（PingFang SC / Microsoft YaHei）、系统 sans-serif。
- 页面标题约 24–28 px；模块标题约 15–17 px；正文约 13–14 px；辅助信息约 11–12 px。
- 以字重和留白组织层级，不用大面积全大写、小字密排或过多粗体。
- 表单标签放在字段上方；辅助文字紧随其后，解释格式、来源或影响。

## 间距、形状与层次

- 间距基于 4 px：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 px。
- 卡片圆角约 12–16 px；输入框与小按钮约 9–11 px；状态标签可用胶囊圆角。
- 描边保持轻薄；卡片优先用浅边框，只有浮层、菜单或重要卡片才加柔和阴影。
- 页面留白要能形成分组；少用连续的边框表格。列表行通过间距、浅底悬停和必要的分隔线区分。
- 一个主要区域只设一个蓝色主按钮。次要操作使用白底描边或文字按钮。

## 应用框架

- 桌面端：左侧导航约 232–248 px；顶部栏约 56–64 px；主内容有舒适边距，内容区最小宽度可伸缩。
- 导航按任务阶段分组，当前项使用浅蓝底、蓝色文字和小图标；避免把所有功能都做成同等权重。
- 学校/数据文件等全局上下文放在顶部或侧栏稳定位置，不与页面内编辑字段混为一体。
- 平板端：侧栏收为图标栏或可展开导航；双栏设置页转为纵向卡片；弹窗按可用宽度变成底部面板或接近全宽的对话框。
- Flutter 实现可将这些 token 映射到 Forui 的主题、按钮、文本字段、下拉框、卡片与对话框；尺寸遵循窗口约束，避免固定宽度导致溢出。

## 控件与交互

- 输入项使用明确标签、可见焦点环和合适的光标提示。日期、学年与名称等可编辑字段看起来像控件，不要只用静态文本伪装。
- 保存或新增操作后给出轻量确认；校验提示贴近字段并说明如何修正。破坏性操作再进行确认。
- 对话框标题说明正在编辑的对象；提交与取消动作放在稳定的底部操作区。
- 点击日历日期可以开始添加或查看例外；月份导航、选择器和标签提供清晰的 hover / focus 状态。
- 键盘可达：Tab 顺序自然，Esc 关闭浮层，Enter 可提交有效表单，焦点环不可被移除。
- 静态 HTML 原型只保存当前页面会话中的演示状态，不代表已经接入 Flutter 或持久化。

## 学期与日历页面约定

- 学期卡片中的学期名称、第 1 教学周起始日、教学周数和课表周期可以编辑；“当前学期”状态、教学周序号和单双周标记是派生信息。当前领域模型只保存教学周锚点与周数，不要单独展示或保存未经支持的学期起止日期。
- 第 1 教学周按 PRD 定义为单周，之后逐周单双交替。停课与补课例外不移动周次锚点。
- **每周上课日不在学期与日历中设置**。上课日和每日节数属于作息结构，按学段分别设置；日历页只提供通往“作息设置”的入口。
- 月历采用周一至周日的行布局；每行左侧显示教学周序号与单 / 双周标记，日期格不重复展示周次标记。
- 月份切换只保留前后月操作；“添加例外”放在本月例外区域，避免挤占月份导航。
- 日历例外至少包含日期、适用范围、类型与说明。停课标记不上课；补课需要映射到所采用的教学周，并可按学段指定所用作息日。
- 全校例外允许在同一日期对不同学段采用不同的作息日；不以单一学校级“周一至周五”假设覆盖全校。
