核心功能

覆盖「资料 → 约束 → 排课 → 课表 → 导出」全流程

支持浏览器直接打开，也提供原生桌面应用；界面现代、操作克制，从资料到课表一条清晰的工作流。

跨学段一贯制

小学部 / 初中部 / 高中部各有独立作息与节次时间，教师可跨学段任课。一套数据，排全校课表。

单双周课表

同一科目可按单周、双周分别设置节数；连堂、同科进度一致等规则按实际出现周次判定。

按天差异作息与晚自习

各学段独立设置上课日与节数，支持按天覆盖（如周五无晚自习、周日有），时段类型可扩展早读 / 晚自习。

自动排课

启发式求解，「正常」档数分钟内完成、硬约束零违规；排不下的课程进入暂放区，待人工处理。

合班课

同一教师、同一科目、多个班级自动合并为一节；跨学段合班按课时钟完全对齐时建立绑定。

免任课与预设

全校 / 学段 / 年级 / 班级四级范围标记无课、自习、教研等活动；科目预设与教师预设按范围精细配置。

调代课与统计

学期中临时调代、设期限、导出调课通知；期末导出教师工作量（应上 / 实上 / 调代，含跨学段合计）。

导入导出打印

配套 Excel 模板批量导入，导出总课表、教师课表、班级课表、值班表与调课通知，打印不依赖本机 Office。

纯本地、离线可用

浏览器版与桌面版均支持纯本地存储，无需账号、不采集任何遥测。换机用备份文件即可继续。

工作流

五步，从零排出一所学校的课表

  1. 1

    基础资料

    学期日历、学段、年级班级、科目、教师，先把全校数据骨架搭起来。

  2. 2

    约束设置

    作息、科目节数、免任课、合班、排课规则，把学校真实规则说清楚。

  3. 3

    自动排课

    一键求解，硬约束零违规；冲突与排不下的课进入暂放区。

  4. 4

    课表编辑

    单双周视图、拖拽微调、调代课；所有改动贴近字段、清晰可见。

  5. 5

    导出打印

    多视图课表、调课通知、工作量统计，一键导出交付。
